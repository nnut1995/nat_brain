# N&P Facebook Reel — ทดสอบหานักเรียนใหม่ 7 วัน

## ขอบเขตที่ตกลง

บันทึกการตัดสินใจจากบทสนทนากับ Nat วันที่ 2026-09-13: เน้นคนไทยใกล้ยิม คลาสแรก 400 บาท งบทดลอง 200 บาท × 7 วัน รวม 1,400 บาท แล้วประเมินกำไรก่อนยิงต่อ ราคาคลาสกลุ่ม 60 นาที 400 บาทสอดคล้องกับข้อมูลเดิม ([[wiki/sources/n-and-p-boxing-gym]])

- โพสต์ที่ Nat เลือก: [Facebook Reel](https://www.facebook.com/reel/1044793744802809)
- สถานะ: บันทึกแผนแล้ว ยังไม่ได้สร้างหรือเปิดโฆษณา และยังไม่ได้เชื่อมบัญชี Meta
- แผนนี้ย่อจาก [[wiki/syntheses/n-and-p-two-plans-local-and-staycation]] ให้เหมาะกับงบทดลอง

## ค่าตั้งต้นที่เสนอ

| รายการ | แผน |
|---|---|
| โครงสร้าง | 1 แคมเปญ / 1 กลุ่มเป้าหมาย / 1 Reel |
| เป้าหมาย | เพิ่มบทสนทนาใน Messenger เพื่อรับจอง ตรวจ objective และ performance goal ในบัญชีจริง |
| กลุ่มเป้าหมาย | อายุ 20–50 ทุกเพศ รัศมีเริ่มต้นประมาณ 5 กม. รอบหมุดยิมที่ตรวจแล้ว ไม่ซ้อนความสนใจหลายชั้น |
| Creative | ใช้ Reel เดิมผ่าน Use existing post หากรองรับ ตรวจสิทธิ์สื่อและปุ่มส่งข้อความก่อนเผยแพร่ |
| Placements | เริ่ม Advantage+ placements ที่รองรับ ตรวจภาพตัวอย่างทุกตำแหน่ง |
| งบ | Lifetime budget 1,400 บาท / 7 วัน เฉลี่ย 200 บาทต่อวัน ลดงบสื่อลงหากวงเงินนี้รวมภาษีหรือค่าธรรมเนียม |
| วันที่เสนอ | 17–23 กันยายน 2026 ยังไม่ใช่วันเริ่มที่ยืนยัน |

วันเริ่มที่เสนอหลบวันปิดประจำ 15–16 ตามข้อมูลเดิม ต้องตรวจตารางปัจจุบันก่อนตั้งจริง ([[wiki/sources/n-and-p-boxing-gym]])

> [!note] ความจุคลาส
> แผนราคาเดิมบันทึกปัญหาคลาสช่วงเย็นเต็มไว้ใน [[wiki/syntheses/n-and-p-pricing-strategy]] ก่อนรับจองให้ตรวจที่ว่างจริง โดยเฉพาะ 18:00–19:00 และเสนอเฉพาะรอบที่รองรับได้

คำแนะนำเรื่อง Use existing post และ placements อ้างอิง [คู่มือ Reels ads ของ Meta](https://www.facebook.com/business/ads/facebook-instagram-reels-ads) ต้องตรวจตัวเลือกในบัญชีจริง

## ร่างข้อความ

ร่างสำหรับเพิ่มต้นแคปชัน ยังไม่ได้แก้โพสต์:

🥊 เริ่มเรียนมวยไทยครั้งแรก ที่ N&P พระราม 2

คลาสกลุ่ม 60 นาที ครั้งละ 400 บาท

ทักแชตคำว่า “เริ่มมวย” เพื่อสอบถามและจองรอบเรียน บอกวันและเวลาที่สะดวกได้เลยครับ

ราคา ระยะเวลา และพื้นที่อ้างอิง [[wiki/sources/n-and-p-boxing-gym]]

## ขั้นตอนรับจองที่เสนอ

1. ตอบราคา ส่งแผนที่ที่ตรวจถูกต้อง และถามประสบการณ์เรียนมวย
2. ถามว่ามาจากแถวไหนและสะดวกวันเวลาใด
3. เสนอรอบที่มีที่ว่างจริง 2 ตัวเลือก ยืนยันชื่อและวันนัด
4. พยายามตอบภายใน 5–15 นาทีช่วงที่มีทีมดูแล
5. บันทึกแหล่งที่มาของลูกค้าและผลจองต่อเนื่องถึงการชำระเงิน

## วัดผลและตัดสินใจ

บันทึกแยกรายคน: วันที่ทัก / มาจากโฆษณาหรือไม่ / นักเรียนใหม่หรือเดิม / เดินทางมาได้ / วันที่จอง / มาเรียนจริง / ยอดจ่าย / แพ็กที่ซื้อ / ต้นทุนให้บริการ ห้ามนับลูกค้าคนเดียวซ้ำเป็นนักเรียนใหม่หลายคน

- วันที่ 1–2: ตรวจปลายทางแชต การตอบกลับ และพื้นที่ของคนทัก
- วันที่ 3–4: ถ้าใช้ราว 600 บาทแล้วยังไม่มีคนที่เดินทางมาได้และสนใจจอง ให้พักตรวจข้อความ พื้นที่ และข้อเสนอ เกณฑ์นี้เป็นข้อเสนอคุมงบ ไม่ใช่ benchmark ตลาด
- วันที่ 7: สรุปยอดใช้จริง คนทัก คนจอง คนมาเรียน และคนจ่าย
- ติดตามกลุ่มคนทักในช่วงทดลองต่ออีก 7 วันเพื่อเก็บผลคนที่นัดภายหลัง แยกยอดคาดหวังจากยอดจริง

สูตร:

- CAC = ค่าโฆษณาจริง ÷ นักเรียนใหม่ที่จ่ายจริงจากโฆษณา ถ้าไม่มีคนจ่ายยังคำนวณค่าจำกัดไม่ได้
- ผลตอบแทนหลังต้นทุนให้บริการ = รายได้ที่ติดตามได้ − ต้นทุนให้บริการที่เกี่ยวข้อง − ค่าโฆษณา
- ROI แคมเปญ = ผลตอบแทนหลังต้นทุนให้บริการ ÷ ค่าโฆษณา
- แพ็กที่ชำระล่วงหน้าต้องหักต้นทุนให้บริการครบแพ็ก ไม่ถือเงินรับทั้งก้อนเป็นกำไร และตัวเลขนี้ยังไม่ใช่กำไรสุทธิของทั้งกิจการ

ตัวอย่างสมมติ: ถ้าเหลือหลังต้นทุนให้บริการ 250 บาทต่อนักเรียนใหม่ ต้องได้อย่างน้อย 6 คนเพื่อครอบคลุมค่าโฆษณา 1,400 บาท เพราะ 6 × 250 = 1,500 บาท ยังไม่มีข้อมูล margin จริงของยิม

ข้อเสนอการยิงต่อ: เมื่อผลตอบแทนที่เกิดจริงหลังต้นทุนเป็นบวกและมีที่ว่าง ค่อยเพิ่มงบรอบถัดไป 20–30% โดยตกลงงบใหม่ก่อน ไม่เพิ่มอัตโนมัติจากยอดทักราคาถูก ผลจากงบน้อยเป็นสัญญาณเบื้องต้น ไม่รับประกันผลระยะยาว

## การเชื่อมข้อมูล

ข้อเสนอรอบแรก: ใช้ Ads Manager แล้วประกบรายงานค่าโฆษณากับทะเบียนจอง/ชำระเงินก่อนทำระบบอัตโนมัติ

สำหรับอนาคต Meta Marketing API รองรับการอ่านผลและจัดการโฆษณาตามสิทธิ์บัญชี ต้องมีแอป บัญชีโฆษณา และ access token ที่เหมาะสม ดู [เอกสาร Meta](https://www.postman.com/meta/facebook-marketing-api/documentation/0zr4mes/facebook-marketing-api-mapi) การเชื่อมยังไม่ได้ดำเนินการ และต้องจับคู่ข้อมูลโฆษณากับยอดชำระเงินจริงเพื่อวัด ROI หน้าร้าน
